Your 5-hour window, on your schedule.

On the $20 Claude Pro and ChatGPT Plus plans, the 5-hour clock starts with your first message. LimitKiller sends that message for you, at 6 a.m. or the minute the last window resets. When you sit down to work, a window is already running and resets sooner.

Why

The cap isn't the problem. The clock is. Start at 9:00, run out by 10:40, and you wait until 2:00. With a 6:00 ping, the window resets at 11:00, while you're still at your desk.

Features

Small script. No babysitting.

One bash file you can read in five minutes. No daemon, no account, no copied tokens.

#1 Schedule

Pick your times

limitkiller schedule 06:00 11:00 pings at the times you choose, every day.

#2 Watch

Back-to-back windows

Checks every 5 minutes and starts the next window as soon as the last one resets, all week.

#3 Both

Claude Code and Codex

Pings whichever of the two you have installed and tracks each tool's window separately.

#4 Private

No stored credentials

Uses your existing claude and codex logins. LimitKiller never copies, exports or uploads a token.

#5 Light

A near-free ping

Claude gets one Haiku message with no tools, hooks, plugins or MCP servers. Codex runs read-only. Reset times are read from local logs, which costs no quota.

#6 Native

launchd and cron

Uses the system scheduler. On a Mac, launchd can read your Keychain login and runs missed pings when the Mac wakes.

How it works

Set it up once.

macOS or Linux, bash and jq. Have claude or codex installed and logged in.

01

Install

Clone the repo and put the script on your PATH.

git clone https://github.com/kenny2077/LimitKiller
ln -s "$PWD/LimitKiller/limitkiller" \
  ~/.local/bin/limitkiller
02

Pick a mode

Fixed times, or chain every window back to back.

limitkiller schedule 06:00 11:00
# or
limitkiller watch
03

Forget it

Check on it when you want. Remove it with one command.

limitkiller status
limitkiller stop
FAQ

Questions.

Does this give me more usage?

No. Your caps stay the same. LimitKiller changes when each 5-hour window starts, so a reset lands while you're working instead of while you're asleep.

How much quota does a ping use?

Very little. Claude gets one short Haiku message with tools, hooks, plugins and MCP servers turned off. Codex gets one read-only codex exec. Watch mode sends about 4–5 pings a day per tool, and each one counts toward your weekly cap.

Does my computer need to be awake?

Yes. A sleeping laptop can't send anything. On macOS, launchd runs a missed ping as soon as the Mac wakes. To wake it on a schedule, run sudo pmset repeat wakeorpoweron MTWRFSU 05:58:00.

Is it allowed?

A ping is one ordinary message from your own logged-in client. We found no rule against it, but read Anthropic's and OpenAI's terms yourself. LimitKiller does not rotate accounts or share them.

What happens when I hit the weekly cap?

LimitKiller reads the reset time from the rejected reply (Claude) or the local logs (Codex) and waits until then. It doesn't send pings that can't succeed.

How do I remove it?

limitkiller stop removes the launchd or cron job. Then delete the repo and ~/.local/state/limitkiller.
